CVIT/NOVA - OPERATOR HELP

CVIT IS A SMALL DISK SYSTEM FOR THE DATA GENERAL NOVA.
THIS FILE IS MEMBER HELP ON THE BOOT VOLUME.  TYPE HELP
AT THE ] PROMPT PRINTS IT AGAIN.

COMMAND - THE ] PROMPT
  COMMANDS ARE CASE-INSENSITIVE.  AN UNKNOWN VERB GETS ?WHAT.

  STA            VOLUME STATUS
  CAT            LIST THE DIRECTORY (ALSO: CATALOG)
  TYPE NAME      PRINT A TEXT MEMBER
  RUN NAME       RUN A SYSTEM MEMBER, E.G. RUN FOCAL
  CTRL-D         (EOT) HALTS THE MACHINE

  MEMBER NAMES ARE 1-10 CHARACTERS: A-Z 0-9 . - _

FOCAL - THE * PROMPT
  START IT WITH RUN FOCAL AT THE ] PROMPT.

  TYPE A NUMBERED LINE TO ENTER IT, E.G.
    1.10 TYPE "HELLO"!
  GO RUNS THE PROGRAM.  WRITE LISTS IT.
  QUIT RETURNS TO THE ] PROMPT.

  COMMANDS: ASK COMMENT DO ERASE FOR GOTO IF QUIT
  RETURN SET TYPE WRITE
  FUNCTIONS: FABS FSGN FITR FSQT

  .SAVE NAME     SAVE THE PROGRAM TO DISK.  SAVING OVER AN
                 EXISTING NAME REPLACES IT; THE OLD VERSION
                 SURVIVES UNTIL THE NEW ONE IS COMPLETE.
  .LOAD NAME     LOAD A PROGRAM FROM DISK.  THIS ERASES THE
                 PROGRAM IN MEMORY FIRST, SO A FAILED LOAD
                 LEAVES AN EMPTY SESSION.

  ENTER .SAVE AND .LOAD ON THEIR OWN LINE AT THE * PROMPT.
  ERRORS ARE REPORTED AS ?CODES; SEE THE MANUAL.
